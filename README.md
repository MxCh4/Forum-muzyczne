# Forum muzyczne 

Projekt statycznej, responsywnej strony internetowej stworzonej w ramach zadania domowego.

## Wykorzystane technologie
- HTML5 (struktura semantyczna)
- CSS3 (Flexbox, Media Queries, zmienne CSS)
- JavaScript

## Funkcjonalności JavaScript
-  Rozwijane menu "hamburger menu" na urządzeniach mobilnych
- Zmiana trybu na ciemny        
- wyświetlanie informacji o artystach
- obsługa walidacji formularza
- funkcja zegara wyświetlająca aktualną datę i czas
